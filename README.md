# Fnac → Allemagne : dashboard

Dashboard du projet final Data Analytics (Eugenia School, M2) : « L'implantation de la Fnac en Allemagne est-elle réalisable et rentable ? »

**Ouvrir le dashboard :** https://romane13long-source.github.io/fnac-allemagne-dashboard/

- 12 onglets, une question par onglet ; filtres : ville candidate, catégorie, achats, loyer.
- Chaque chiffre indique ce qu'il mesure, sa nature (mesuré, estimation, hypothèse, simulé) et sa source.
- Brique IA : chaque onglet construit un prompt à partir de ses chiffres (visible dans la page). Sur ce lien public, Claude n'est pas appelé (pas de clé d'API) : un texte calculé sans IA s'affiche à la place, signalé comme tel.

Ce dépôt ne contient que la page publiée (un fichier HTML autonome, sans cookie ni traceur). Le code de collecte, de nettoyage et de modélisation est dans le dépôt principal de l'équipe (privé).

Projet étudiant, sans lien avec la Fnac ni le groupe Fnac Darty. Données : Eurostat (CC BY 4.0), Destatis (Datenlizenz Deutschland – Namensnennung 2.0), rapports annuels publics (Fnac Darty, CECONOMY), sites officiels d'Expert et d'Euronics.
